# 🧠 Psych Ward OS: True Microkernel Edition

**Psych Ward OS** — это экспериментальная операционная система на базе микроядра **seL4**, реализующая принцип наименьших привилегий и полную изоляцию компонентов. В отличие от монолитных систем, здесь даже драйверы устройств и системные службы вынесены в пространство пользователя (User-space)[cite: 1].

## 🏗 Архитектура: Модульная Изоляция

Проект перешел от монолитного приложения к модульной структуре. Теперь пользовательское окружение разделено на независимые бинарники, каждый из которых работает в собственной песочнице[cite: 1]:

1.  **UART Driver (`uart_driver.cpp`):** Изолированный сервер терминала. Владеет физическим фреймом ввода-вывода и обрабатывает прерывания клавиатуры[cite: 1].
2.  **Timer Driver (`timer_driver.cpp`):** Служба системного времени. Управляет RTC и предоставляет сервис засыпания через IPC[cite: 1].
3.  **Shell (`shell.cpp`):** Пользовательская оболочка, обеспечивающая интерфейс управления и порождение новых процессов[cite: 1].

**Rootserver (The Doctor)** в `main.cpp` выполняет роль верховного судьи: управляет адресными пространствами, раздает права (Capabilities) и координирует системные вызовы[cite: 1].

## 🚀 Ключевые возможности

*   **User-Space Driver Isolation:** Драйверы работают как обычные процессы. Ошибки в коде драйвера не приводят к панике ядра[cite: 1].
*   **Process Lifecycle (POSIX-like):** Реализованы системные вызовы `SYS_EXEC` (запуск ELF с передачей `argc/argv`), `SYS_WAIT` (ожидание завершения) и `SYS_EXIT` (самозавершение)[cite: 1].
*   **Demand Paging:** Динамический аллокатор страниц выделяет память на лету при возникновении Page Fault[cite: 1].
*   **Zero-Copy Shared Memory Heap:** Процессы могут динамически запрашивать общие физические фреймы памяти (`SYS_SHM_GET`) для мгновенного обмена данными напрямую друг с другом, минуя ядро.
*   **Background Execution & Daemons:** Поддержка запуска независимых фоновых процессов (с помощью символа `&`) и режима `--daemon` для работы сервисов без блокировки TTY.

## 🛠 Команды оболочки

Оболочка поддерживает динамический промпт, отображающий текущий PID процесса (например, `sandbox[3]>`).

| Команда | Описание |
| :--- | :--- |
| `ps` | Список активных процессов с именами и PID[cite: 1] |
| `pid` | Вывод PID текущей оболочки |
| `exec <file> [args] [&]` | Запуск процесса с аргументами. `&` в конце запускает процесс в фоне |
| `shm <id> <read/write> [text]` | Запись или чтение межпроцессной разделяемой памяти (Shared Memory) |
| `exit` | Завершение текущей оболочки[cite: 1] |
| `kill <pid>` | Принудительная терминация процесса[cite: 1] |
| `echo / cat` | Базовая работа с RAM-диском через системный VFS[cite: 1] |

*(Совет: используйте флаг `--daemon` при фоновом запуске `exec shell --daemon &`, чтобы процесс не пытался читать ввод с клавиатуры).*

## 💻 Сборка и запуск

### Зависимости:
*   `arm-none-eabi` или `aarch64-linux-gnu` toolchain
*   `QEMU` (для эмуляции virt/cortex-a53)
*   `Ninja` и `CMake`

### Компиляция:
```bash
mkdir build && cd build
../init-build.sh -DPLATFORM=qemu-arm-virt -DAARCH64=1
ninja
```

### Запуск в QEMU:
```bash
qemu-system-aarch64 \
    -machine virt,virtualization=on \
    -cpu cortex-a53 \
    -nographic \
    -serial mon:stdio \
    -m size=1024M \
    -kernel images/sel4test-driver-image-arm-qemu-arm-virt
```

```bash
git add .

git push origin main
```
