# 🧠 Psych Ward OS: True Microkernel Edition

**Psych Ward OS** — это экспериментальная операционная система на базе микроядра **seL4**, реализующая принцип наименьших привилегий и полную изоляцию компонентов. В отличие от монолитных систем, здесь даже драйверы устройств вынесены в пространство пользователя (User-space).



## 🏗 Архитектура

Система построена на базе микроядра seL4 (AArch64) и следует философии "ничего лишнего в ядре". 

### Основные компоненты:
*   **Rootserver (The Doctor):** Управляет ресурсами, памятью и жизненным циклом процессов. Реализует системные вызовы для управления системой[cite: 1].
*   **UART Driver:** Изолированный процесс, имеющий прямой доступ к железу через маппинг физических адресов, но ограниченный своей песочницей[cite: 1].
*   **Shell (The Patient):** Пользовательский интерфейс, который взаимодействует с драйвером напрямую через P2P IPC[cite: 1].

---

## 🚀 Ключевые возможности

*   **User-Space Driver Isolation:** Драйвер UART работает как обычный процесс. Падение драйвера не приводит к панику ядра[cite: 1].
*   **Peer-to-Peer IPC:** Оболочка и Драйвер общаются напрямую через Endpoint-ы сеанса, минуя обработку текста внутри Rootserver[cite: 1].
*   **Demand Paging:** Реализован динамический аллокатор страниц. При обращении к неразмеченной памяти (Page Fault) ядро на лету выделяет физический фрейм и возобновляет работу процесса[cite: 1].
*   **VFS (CPIO):** Система парсит встроенный в образ RAM-диск формата CPIO для запуска исполняемых ELF-файлов и чтения данных[cite: 1].
*   **Zero-Copy Shared Memory:** Использование разделяемой памяти для быстрой передачи данных между ядром и пользователем[cite: 1].

## 🛠 Команды оболочки

После запуска вам доступен набор стандартных утилит:

| Команда | Описание |
| :--- | :--- |
| `ls` | Список файлов во встроенной VFS (RAM-диск)[cite: 1] |
| `ps` | Список активных процессов и их состояний[cite: 1] |
| `exec <file>` | Запуск нового процесса из ELF-бинарника[cite: 1] |
| `kill <pid>` | Принудительная остановка процесса (Suspend TCB)[cite: 1] |
| `help` | Проверка связи с изолированным драйвером[cite: 1] |

## 💻 Сборка и запуск

### Зависимости:
*   `arm-none-eabi` или `aarch64-linux-gnu` toolchain
*   `QEMU` (для эмуляции virt/cortex-a53)
*   `Ninja` и `CMake`

### Компиляция:
```bash
mkdir build && cd build
../init-build.sh -DPLATFORM=qemu-arm-virt -DAARCH64=1
ninja
```

### Запуск в QEMU:
```bash
qemu-system-aarch64 \
    -machine virt,virtualization=on \
    -cpu cortex-a53 \
    -nographic \
    -serial mon:stdio \
    -m size=1024M \
    -kernel images/sel4test-driver-image-arm-qemu-arm-virt
```
